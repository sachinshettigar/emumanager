# Prompts

Copy-paste prompt templates for common work. Harness-agnostic — paste into whatever tool you're
using. `<angle brackets>` are fill-ins.

| File | For |
| --- | --- |
| `onboard.md` | First message when starting a fresh session in any tool |
| `implement-task.md` | Ask the agent to implement one `.agent/tasks/` item |
| `review-change.md` | Review a diff / PR before merge |
| `handoff.md` | End a session cleanly so the next tool can pick up |
| `plan-milestone.md` | Turn a milestone into `.agent/tasks/` entries |
