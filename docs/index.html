Android emulators · Windows · macOS · Linux

Android emulators without Android Studio.

A small, fast desktop app to create, launch, track, and share Android Virtual Devices. It brings its own SDK — no IDE, no sdkmanager incantations.

Download View source

Free & open source (MIT). Builds are unsigned — first launch needs one extra click.

Made for people who know their machine but not Android tooling.

Pick a device and an Android version, and Emulator Studio downloads exactly the SDK pieces it needs into its own folder. Then launch, watch the logs, and hand the setup to a teammate as a one-file recipe. Nothing touches a system Android install.

What it does

Everything to run an emulator, nothing you don't need.

📦

SDK from zero

Bootstraps command-line tools, platform-tools, the emulator, and system images into its own data directory. Reuses a real Android SDK if it finds one.

✨

Guided create & launch

Browse devices by form factor and API level, name it, pick RAM and storage, launch with a real device frame. Your desktop keyboard works inside it.

📇

Live tracking

Every emulator you've made with its state — stopped, booting, running. Relaunch, stop, wipe, rename, delete from one list.

🪵

Watch it run

A logcat viewer with level, tag, and text filters and colour-coded priorities, plus a facts strip — model, Android version, battery, storage.

🔁

Share a setup

Export any emulator to a portable .emuprofile recipe. Import one and it resolves and downloads what's missing, then rebuilds it locally.

🖥️

Reads your host

Detects KVM, WHPX, or Hypervisor.framework and tells you whether emulators will be hardware-accelerated — with a one-time helper for fixes that need admin rights.

How it works

Three steps, then it's on your dashboard.

STEP 1

Choose

Pick a device and an Android version. Images you already have are marked ready to launch instantly.

STEP 2 · AUTOMATIC

Prepare

Emulator Studio fetches just the SDK pieces it needs into its own folder. No Android Studio, no terminal.

STEP 3

Run

Launch it and watch the logs. Export the setup as a .emuprofile to hand to a teammate.
